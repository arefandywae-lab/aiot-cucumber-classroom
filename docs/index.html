AIoT Cucumber Classroom

เรียนรู้ AIoT แบบลงมือทำ: ให้บอร์ด Cucumber วัดอุณหภูมิ ความชื้น และความดันอากาศ ส่งข้อมูลขึ้นหน้าเว็บ/Telegram แล้วให้ AI ช่วยบอกว่าอะไรผิดปกติ และตอบคำถามเป็นภาษาไทย

เหมาะกับ นักเรียนมัธยมปลาย (ไม่ต้องเคยเขียนโปรแกรมมาก่อน) ใช้เวลาประมาณ 3 ชั่วโมง

ระบบทำงานอย่างไร

🌡 บอร์ด Cucumberอ่านเซนเซอร์ทุก 3 วินาที
→ WiFi/MQTT →
🖥 Gatewayเก็บข้อมูล + API (Docker)
→
🤖 AIตรวจผิดปกติ + แชท LLM (Colab)
→
📱 UIหน้าเว็บ หรือ Telegram

ลองใช้งานหน้าเว็บ

หน้าเว็บนี้เชื่อมกับ gateway ของคุณเอง ใส่ URL ของ gateway (เช่นจาก ngrok) แล้วกดเปิด ถ้ายังไม่มี gateway ให้ทำบทที่ 3 ก่อน

บทเรียน

  1. เริ่มต้นกับ AIoT — IoT คืออะไร AI เข้ามาช่วยตรงไหน
  2. เซนเซอร์วัดอะไรได้ — BMP280 และ HTS221
  3. ต่อบอร์ด Cucumber — อัปโหลดโปรแกรมลงบอร์ด
  4. ส่งข้อมูลผ่าน MQTT — เปิด gateway ด้วย Docker
  5. หน้าเว็บและ Telegram — ดูข้อมูลบนมือถือ
  6. AI ตรวจความผิดปกติ — สถิติ z-score
  7. AI แชทบน Colab — ถามบอร์ดเป็นภาษาไทย

ตัวเลือกตามอุปกรณ์ที่มี

ตัวเลือก
ไม่มีบอร์ดใช้ devices/simulator.py ส่งข้อมูลจำลองเข้า gateway แทนบอร์ด
AI ไม่ต้องใช้อินเทอร์เน็ตตัวตรวจผิดปกติและคำตอบแบบกฎง่ายๆ ทำงานบนเครื่องเอง ไม่ต้องมี LLM
AI แบบ LLMรันบน Google Colab (ไม่ต้องมี GPU เอง) หรือรัน Ollama บนคอมพิวเตอร์เอง
UIหน้าเว็บของโปรเจกต์ หรือ Telegram Mini App ใช้ gateway ตัวเดียวกัน
