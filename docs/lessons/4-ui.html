บทที่ 4

หน้าเว็บและ Telegram

หน้าเว็บ (gateway/mqtt_collector/miniapp.html) เขียนด้วย HTML/CSS/JavaScript ล้วน ไม่มีไลบรารีเพิ่ม ดึงข้อมูลจาก /api/summary ทุก 3 วินาที แล้ววาดการ์ดกับกราฟ

ทางเลือก A: เปิดในเบราว์เซอร์

เปิด http://localhost:5001/app บนคอมพิวเตอร์ หรือถ้าอยากดูบนมือถือที่อยู่ WiFi เดียวกัน ใช้ http://IP-ของคอม:5001/app

ทางเลือก B: Telegram Mini App

Telegram บังคับให้เป็น https เราจึงต้องมีลิงก์สาธารณะ ใช้ ngrok ทำ port forwarding:

ngrok http 5001
  1. คุยกับ @BotFather พิมพ์ /newbot เพื่อได้ token
  2. ใส่ TELEGRAM_BOT_TOKEN และ MINIAPP_URL (ลิงก์ https จาก ngrok) ใน gateway/.env
  3. docker compose up -d mqtt_collector แล้วเปิดแชทกับบอท กดปุ่ม Sensors หรือพิมพ์ /app
ตั้ง TELEGRAM_ALLOWED_CHAT_ID ด้วย ไม่งั้นคนแรกที่ส่ง /start ให้บอทจะกลายเป็นเจ้าของ (หา chat id จาก @userinfobot)
ระวัง token ของบอทเหมือนรหัสผ่าน อย่าส่งให้ใครหรืออัปโหลดขึ้น GitHub ลิงก์ ngrok แบบฟรีจะเปลี่ยนทุกครั้งที่เปิดใหม่ ต้องแก้ MINIAPP_URL ใหม่

แล้วใครเปิดหน้านี้ได้บ้าง

ใครมีลิงก์ก็เปิดดูได้ แต่ Telegram จะแนบข้อมูลผู้ใช้ที่ เซ็นลายเซ็นไว้ มาด้วย gateway ตรวจลายเซ็นนั้นที่ /api/verify (ดูฟังก์ชัน check_init_data ใน rest_app.py) เพื่อรู้ว่าเปิดมาจาก Telegram จริง

ใช้หน้าเว็บจาก GitHub Pages
