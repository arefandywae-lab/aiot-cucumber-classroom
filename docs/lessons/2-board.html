บทที่ 2

ต่อบอร์ด Cucumber

โปรแกรมของบอร์ดอยู่ในโฟลเดอร์ devices/cucumber/ ใช้ PlatformIO (ปลั๊กอินของ VS Code หรือ pip install platformio)

ขั้นที่ 1: ตั้งค่า WiFi และที่อยู่ gateway

แก้ devices/cucumber/include/Config.h ใส่ชื่อ WiFi และ IP ของคอมพิวเตอร์ที่จะรัน gateway (Mac: ipconfig getifaddr en0 หรือ en1)

#define WIFI_SSID        "YOUR_WIFI_NAME"
#define MQTT_BROKER_IP   "192.168.1.100"

คัดลอก secrets.h.example เป็น secrets.h แล้วใส่รหัส WiFi (ไฟล์นี้ถูกกันไว้ไม่ให้ขึ้น GitHub จะได้ไม่หลุดรหัสผ่าน)

ขั้นที่ 2: อัปโหลด

cd devices/cucumber
pio run -t upload
pio device monitor

ใน Serial Monitor ควรเห็นบรรทัดแบบนี้ทุก 3 วินาที

[Sensor] BMP280: T=29.86 C, P=1009.86 hPa | HTS221: T=29.33 C, RH=60.34 %
[MQTT] Published -> /cn466/data: {"node":1,"value":29.86}

ถ้าไม่ขึ้น

  • อัปโหลดไม่ได้ / พอร์ตหาย กดปุ่ม BOOT ค้างไว้ แล้วกด RESET หนึ่งครั้ง จากนั้นสั่งอัปโหลดใหม่
  • ต่อ WiFi ไม่ได้ ตรวจว่าเป็นคลื่น 2.4 GHz และรหัสถูกต้อง
  • ต่อ MQTT ไม่ได้ IP ใน Config.h ต้องตรงกับคอมพิวเตอร์ และไฟร์วอลล์ต้องไม่บล็อก port 1883
