3 ส่งข้อมูลผ่าน MQTT

MQTT เป็นเหมือน "ไปรษณีย์" ของ IoT: บอร์ดส่งข้อความเข้า topic (เหมือนตู้จดหมาย) ใครสนใจก็มา subscribe ตัวกลางเรียกว่า broker (เราใช้ Mosquitto) ข้อความของเราหน้าตาแบบนี้

topic:   /cn466/data
payload: {"node": 3, "value": 29.33}

เปิด gateway ด้วย Docker

gateway คือโปรแกรมที่รับข้อความ เก็บลงฐานข้อมูล และเปิด API ให้หน้าเว็บมาอ่าน

cd gateway
cp .env.example .env     # ไม่ต้องแก้อะไรก็ใช้ได้
docker compose up -d --build

ตรวจว่าทำงาน: เปิด http://localhost:5001/app หรือรัน

curl localhost:5001/api/summary
Endpointทำอะไร
GET /api/summaryค่าล่าสุดของทุก node + ข้อมูลย้อนหลังสำหรับกราฟ
GET /api/anomalyAI ตรวจความผิดปกติ (บทที่ 5)
POST /api/askAI แชท (บทที่ 6)

port สำคัญ

gateway ฟังที่ port 5000 ใน Docker แต่เรา map ออกมาเป็น 5001 บนเครื่อง เพราะ macOS ใช้ port 5000 อยู่แล้ว
