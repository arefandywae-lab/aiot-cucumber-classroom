บทที่ 0

เริ่มต้นกับ AIoT

IoT (Internet of Things) คือสิ่งของที่มีเซนเซอร์และต่อเน็ตได้ ส่วน AI คือโปรแกรมที่ "เรียนรู้หรือตัดสินใจ" จากข้อมูล เมื่อรวมกันเป็น AIoT เราจะได้ระบบที่ไม่ได้แค่วัดค่า แต่ช่วยตีความให้ด้วย

เราจะสร้างอะไร

  • สถานีวัดอากาศในห้องเรียน อ่านค่าทุก 3 วินาที
  • หน้าเว็บ/Telegram แสดงค่าและกราฟ
  • AI 2 แบบ: (1) ตรวจว่าค่าผิดปกติไหม (2) ตอบคำถามเช่น "ตอนนี้ร้อนไหม"

ของที่ต้องมี

รายการหมายเหตุ
บอร์ด Cucumber R (ESP32-S2) พร้อมเซนเซอร์ BMP280, HTS221ไม่มีก็ใช้ตัวจำลองได้
คอมพิวเตอร์ (Mac/Windows/Linux) ติดตั้ง Docker และ Python 3.10+ใช้เป็น gateway
WiFi 2.4 GHz ที่บอร์ดและคอมพิวเตอร์อยู่วงเดียวกันบอร์ดต่อ 5 GHz ไม่ได้
บัญชี Google (สำหรับ Colab) และ Telegram (ถ้าอยากใช้บนมือถือ)ไม่บังคับ
ก่อนเริ่ม ทำเช็กลิสต์ใน เตรียมเครื่องมือ ให้ครบ (ใช้เวลาประมาณ 15 นาที) ถ้าไม่มีบอร์ด อ่าน ไม่มีบอร์ด ใช้ตัวจำลอง แล้วทำต่อได้ทุกบท

ภาพรวมแต่ละบท: เรียนอะไร ได้อะไร

บทได้เรียนลงมือทำ
1เซนเซอร์แปลงโลกจริงเป็นตัวเลขเลื่อนแถบค่า ดูข้อความที่บอร์ดส่ง
2อัปโหลดโปรแกรมลงบอร์ดดูค่าใน Serial Monitor
3MQTT และ gatewayเปิด Docker, เรียก API ด้วย curl
4หน้าเว็บ/Telegramดูกราฟบนมือถือ
5z-score ตรวจผิดปกติสนามเล่นในหน้านี้ + Colab
6LLM ตอบคำถามจากข้อมูลจริงเปิด Colab ด้วยปุ่มเดียว
