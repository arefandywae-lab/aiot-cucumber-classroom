6 AI แชทบน Colab

AI แบบที่สองคือ LLM (โมเดลภาษาขนาดใหญ่) ที่อ่านค่าเซนเซอร์ล่าสุดแล้วตอบคำถามเป็นภาษาไทย เช่น "ตอนนี้ร้อนไหม" "มีอะไรผิดปกติหรือเปล่า"

เลือกที่รัน AI

ที่รันเหมาะกับวิธี
Google Colabเครื่องไม่แรง ไม่มี GPUเปิดโน้ตบุ๊ก ai/colab/cucumber_llm.ipynb เลือก GPU T4 รันทุกเซลล์ จะได้ลิงก์ trycloudflare.com
คอมพิวเตอร์เองมี RAM ≥ 8 GBติดตั้ง Ollama แล้ว ollama pull qwen2.5:3b ใช้ OLLAMA_URL=http://host.docker.internal:11434
ไม่รัน LLMไม่มีเน็ต/ไม่อยากตั้งค่าเว้น OLLAMA_URL ว่าง ระบบตอบด้วยกฎง่ายๆ

เมื่อได้ลิงก์ ใส่ใน gateway/.env แล้วรีสตาร์ท

OLLAMA_URL=https://xxxx.trycloudflare.com
OLLAMA_MODEL=qwen2.5:3b
docker compose up -d mqtt_collector

มันตอบจากอะไร

gateway ไม่ได้ให้ LLM "เดา" แต่ส่งค่าเซนเซอร์ล่าสุดและผลตรวจผิดปกติไปในคำถามด้วย (เรียกว่า grounding) พร้อมคำสั่งให้ตอบจากข้อมูลที่ให้เท่านั้น ใต้คำตอบจะบอกเสมอว่า "ตอบโดย LLM" หรือ "ตอบโดยกฎง่ายๆ"

ลองทำ ถามว่า "ตอนนี้ร้อนไหม" "ความชื้นเท่าไหร่" "พรุ่งนี้ฝนตกไหม" แล้วสังเกตว่าคำถามสุดท้ายโมเดลควรบอกว่าข้อมูลไม่พอ ไม่ใช่เดาตัวเลข
ระวัง ลิงก์ Colab ใครได้ไปก็ใช้โมเดลของคุณได้ อย่าแชร์ต่อ และ LLM ตอบผิดได้ ใช้ช่วยอธิบายเท่านั้น อย่าใช้ตัดสินใจเรื่องความปลอดภัย
