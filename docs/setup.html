เตรียมเครื่องมือ

ทำครั้งเดียว ใช้เวลาประมาณ 15 นาที ทำตามลำดับแล้วติ๊กเช็กลิสต์ท้ายหน้า ถ้าไม่มีบอร์ด ข้ามขั้น PlatformIO ได้

  1. Docker Desktopใช้รัน gateway (Mosquitto + API) ดาวน์โหลดที่ docker.com เปิดโปรแกรมทิ้งไว้จนไอคอนปลาวาฬนิ่ง ต้องมีพื้นที่ดิสก์ว่างอย่างน้อย 5 GB
  2. Python 3.10 ขึ้นไปMac: brew install python · Windows: ติ๊ก “Add to PATH” ตอนติดตั้งจาก python.org แล้วติดตั้งไลบรารีสำหรับตัวจำลอง
pip install paho-mqtt
  1. Gitใช้โหลดโปรเจกต์ (git clone) หรือกดปุ่ม Code → Download ZIP บน GitHub แทนก็ได้
  2. PlatformIO(เฉพาะถ้ามีบอร์ด) ติดตั้งส่วนขยาย PlatformIO IDE ใน VS Code หรือรัน pip install platformio
  3. ngrok(เฉพาะถ้าจะใช้ Telegram) สมัครฟรีที่ ngrok.com แล้วทำตามขั้นตอนติดตั้งและ ngrok config add-authtoken ...
  4. บัญชี Googleสำหรับ Colab ล็อกอินที่ colab.research.google.com ให้เห็นหน้าโน้ตบุ๊กได้ก็พอ

ตรวจความพร้อม (2 นาที)

docker --version
docker run --rm hello-world     # ต้องขึ้น Hello from Docker!
python3 --version
pio --version                    # ถ้ามีบอร์ด
git --version
  • docker run hello-world สำเร็จ
  • Python เป็น 3.10 ขึ้นไป และ pip install paho-mqtt ผ่าน
  • ได้โปรเจกต์มาแล้ว: git clone https://github.com/arefandywae-lab/aiot-cucumber-classroom
  • เปิดลิงก์ Colab ในบทที่ 6 ได้ (ล็อกอินแล้ว)
  • (ถ้ามีบอร์ด) pio --version ทำงาน และเสียบสาย USB แล้วเห็นพอร์ตใหม่
เช็กอย่างรวดเร็ว เปิด gateway ทดสอบ cd gateway && cp .env.example .env && docker compose up -d --build แล้วเปิด localhost:5001/app ถ้าเห็นหน้าเว็บ (แม้ยังไม่มีข้อมูล) เครื่องของคุณพร้อมแล้ว
ติดปัญหา ดู แก้ปัญหา ก่อน ส่วนใหญ่เป็นเรื่อง Docker ยังไม่พร้อม หรือพอร์ตชน
